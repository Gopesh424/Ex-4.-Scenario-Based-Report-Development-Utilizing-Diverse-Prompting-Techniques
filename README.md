# Ex-4.-Scenario-Based-Report-Development-Utilizing-Diverse-Prompting-Techniques

Objective: The goal of this experiment is to design and develop an AI-powered chatbot that can handle customer inquiries, provide support, and improve customer experience in a retail environment. Create prompts using various AI prompting techniques to guide your experiment, data collection, analysis, and report creation.
## Aim: 

To design, implement, and evaluate an AI chatbot that can effectively respond to retail customer queries, provide product information, resolve complaints, and 

enhance customer satisfaction through intelligent interaction.

## Algorithm: 

Problem Definition – Identify customer support needs in retail (order tracking, product queries, complaint resolution).

Prompt Design – Develop prompts using different prompting techniques (translation, storytelling, cloze, reasoning, task prioritization, etc.).

Model Interaction – Execute the prompts on the AI model to generate responses.

Data Collection – Record responses for analysis.

Evaluation – Analyze responses based on accuracy, coherence, creativity, reasoning, and effectiveness.

Result Derivation – Conclude chatbot’s capabilities and limitations in handling retail customer inquiries.

## Prompt:

Translation: “Translate: ‘Where is my order?’ into French.”

Story Generation: “Write a story about a customer ordering a product online.”

Fill-in-the-Blank: “Your order has been _______ successfully.”

Counterfactual Reasoning: “If the product is out of stock, what should the chatbot suggest?”

Code Generation: “Write Python code to check if an order ID exists in the database.”

Trivia/Factual Q&A: “Who is the founder of our retail company?”

Cause and Effect: “What happens if a customer doesn’t receive an order on time?”

Object Counting: “A cart has 2 shirts, 1 shoe, and 3 belts. How many items total?”

Multi-lingual + Summarization: “Translate return policy into Spanish and summarize in English.”

Task Prioritization: “Prioritize: refund request, product info, track order.”

## Result:

Translation confirmed chatbot’s ability for multilingual support.

Story generation showed creativity and empathy in responses.

Cloze tasks validated chatbot’s ability to fill structured replies.

Counterfactual reasoning proved logical thinking for problem-solving.

Code generation illustrated chatbot’s integration potential with retail systems.

Trivia tasks showed factual knowledge retrieval.

Cause-and-effect reasoning improved escalation handling.

Object counting validated numerical/cart reasoning.

Multi-lingual + summarization enhanced global customer reach.

Task prioritization ensured efficient handling of critical issues first.
